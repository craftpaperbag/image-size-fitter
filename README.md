# image-size-fitter

PNG / JPEG 画像を、指定したファイルサイズの上限以内に一括で変換するツールです。HTMLファイル1つで動き、インストールは要りません。

- 画像はブラウザの中だけで処理し、外部へは送信しません（通信処理を持たず、オフラインで動作します）
- 外部ライブラリ・CDN・Webフォントは使っていません

## 使い方

1. `image-compressor.html` をダウンロードし、Microsoft Edge または Google Chrome で開きます
2. 画像（フォルダごとでも可）をドロップするか、「ファイルを選択」から選びます
3. 一覧で推奨形式と変換後のサイズを確認し、必要なら形式を切り替えます
4. 「ZIPでまとめて保存」「フォルダを選んで保存」「1件ずつ保存」のいずれかで保存します
5. 必要なら「ファイル名をCSVで保存」で、出力ファイル名の一覧を CSV（1列・見出しなし）で保存します。前に付ける文字（例：`img/`）を入れると `img/20261105.jpg` のようになり、Webサーバ上の画像パスとして他のCSVに貼り付けられます

初期値の上限は JPEG 300KB、PNG 120KB です。画面の「設定」から変更できます。

## しくみ

- 画像ごとに PNG と JPEG の両方を作り、どちらも上限内に収めてから、元画像との見た目の差（SSIM ベースの画質スコア）が小さい方を推奨します
- JPEG は品質を二分探索し、上限以下で最も高い品質を選びます。最低品質でも収まらない場合は縮小します
- PNG は可逆圧縮なので品質の設定がありません。無加工 → 色数を保ったパレット化 → 減色 → 縮小 の順に試します
- 透過を含む画像は PNG を初期選択します。JPEG に切り替えると透過部分は白になります
- 出力ファイル名は元の名前のまま拡張子だけ変え、重複する場合は `_2`, `_3` … を付けます

詳しい設計はHTMLファイル冒頭のコメントを参照してください。

## 動作環境

Web Worker、OffscreenCanvas、CompressionStream に対応したブラウザ（Edge / Chrome の最新版など）。

## テスト（開発用）

ツール自体は外部依存なしで動きます。テストだけ Playwright を使います。

```sh
npm install
npx playwright install chromium
npm test
```

スクリーンショットは `tests/output/` に保存されます。
